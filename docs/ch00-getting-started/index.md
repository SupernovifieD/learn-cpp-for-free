# 0. Introduction / Getting Started

Before you write real programs, you need to know what a program is and how your computer turns text you type into something it can run. This chapter explains those ideas, helps you install the tools, and walks you through building your first program. It also sets up your compiler so that it helps you learn instead of letting mistakes slip by.

## What you will be able to do after this chapter

- Explain what a program is, and how a compiler and a linker turn source code into one.
- Describe where C++ came from and what a language standard is.
- Install a compiler and a code editor or IDE on your own computer.
- Build and run a first program, and recognize the most common beginner problems.
- Configure your compiler for learning: strict warnings, no compiler extensions, and a known language standard.
