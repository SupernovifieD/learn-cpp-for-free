# 1. C++ Basics

This chapter teaches the smallest building blocks of a C++ program: statements, variables, input and output, operators and expressions. By the end you will write short programs that read numbers from the keyboard, calculate with them and print the results, and you will know how to avoid the mistakes that beginners make most often.

## What you will be able to do after this chapter

- Read a short program and explain what each statement does.
- Define variables, give them values and print them.
- Read numbers from the keyboard and calculate with them.
- Explain why an uninitialized variable is a bug that the compiler may not catch.
- Choose clear names and format your code consistently.
- Build a small program one step at a time.
