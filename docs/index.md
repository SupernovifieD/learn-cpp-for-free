# The C++ Book

**The C++ Book** is a free, open-source course in modern C++. It starts with the first program you ever write and builds up one lesson at a time, so you do not need any programming experience. If you already program in another language, you can read it as a careful introduction to C++.

[Start reading](ch00-getting-started/01-introduction-to-these-tutorials.md){ .md-button .md-button--primary }

## How to read this book

- Read the lessons in order. Each one builds on the ones before it.
- Type the code yourself instead of pasting it. Your fingers will teach you things your eyes skip.
- Press ++n++ for the next page and ++p++ for the previous page, or use the links at the bottom of every page. Press ++s++ to search.
- Look at [Conventions used in this book](conventions.md) to see how code, callouts and tabs appear.
